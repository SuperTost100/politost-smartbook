The Smartbook mark: an open book (three page edges at 50 / 70 / 90% ink) with a gold bookmark ribbon.

- `ptsb-mark-light.svg`: ink `#15181e`, ribbon `#b7790c`, for light grounds (`bg`, `page`, `surface`).
- `ptsb-mark-dark.svg`: ink `#e8eaef`, ribbon `#f4b942`, for dark grounds.
- `ptsb-mark-mono.svg`: solid black, one-colour print (Paged.js print, fax, stamps).
- `ptsb-mark-small-light.svg` / `-dark.svg`: two thicker pages, for 16–31px (favicons, tiny avatars).
- `ptsb-lockup-light.svg` / `-dark.svg`: mark + "Smartbook" in Figtree 700, outlined; 72px tall artboard, use at 28–36px height.
- `ptsb-app-icon.svg`, `ptsb-app-icon-1024.png`: white pages and gold ribbon on teal `#0f6e66`, 22% corner radius; PWA and store icon. `ptsb-app-icon-small.svg` below 32px (favicon).
- PNG app icons at 1024, 512, 256, 128 (full mark) and 64, 32, 16 (small mark). Use the 1024 PNG for PWA / store icons, 32 and 16 for favicons.
