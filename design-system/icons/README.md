# Icons

Lucide (ISC license), lucide-static 1.49.0. In the app import from `lucide-react` with `strokeWidth={1.75}`. `ptsb-icons.svg` is a sprite of the set used in the design (`<svg><use href="ptsb-icons.svg#sigma"/></svg>`), for docs, print and mockups.

Sections: `book-open` Capitoli, `sigma` Formulario, `pencil-line` Esercizi, `graduation-cap` Esami, `terminal` Laboratorio, `chart-line` Grafici.
