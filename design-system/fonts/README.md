# Fonts

- Newsreader (variable, weight 200 to 800, optical size 6 to 72, roman and italic), by Production Type. SIL Open Font License 1.1. Latin subset from `@fontsource-variable/newsreader` 5.3.0 (opsz files).
- Hanken Grotesk (variable, weight 100 to 900, roman and italic), by Hanken Design Co. SIL Open Font License 1.1. Latin subset from `@fontsource-variable/hanken-grotesk` 5.3.0.
- JetBrains Mono (variable, weight 100 to 800), by JetBrains. SIL Open Font License 1.1. Used for code only.

Latin covers Italian and English. The app bundles these files and loads nothing from the network. Add the `latin-ext` subsets from Fontsource if a book needs more languages. KaTeX keeps its own fonts.
